# F.L.E.G. ONE — Architecture Decisions

## Decision 001 — React

### Decision

Use React for the frontend.

### Reason

The project requires reusable UI components and React is suitable for
component-based frontend development.

---

## Decision 002 — Vite

### Decision

Use Vite as the React development/build tool.

### Reason

Vite provides a simple and fast development environment.

---

## Decision 003 — CSS

### Decision

Use standard CSS instead of Tailwind CSS.

### Reason

The project is primarily a frontend UI assignment and standard CSS provides
direct control over the design system and responsive behavior.

---

## Decision 004 — Static Data

### Decision

Use JavaScript mock data files.

### Reason

The assignment does not require a backend or database.

---

## Decision 005 — Single Page

### Decision

Build the initial project as a single-page landing page.

### Reason

The assignment is specifically focused on a landing page and does not
require multiple routes.

---

## Decision 006 — No Backend

### Decision

Do not implement backend functionality.

### Reason

Backend, authentication, payment and real registration are explicitly
outside the scope of the assignment.

---

## Decision 007 — Minimal Dependencies

### Decision

Avoid unnecessary third-party libraries.

### Reason

The project should remain simple, maintainable and easy to understand.
