# F.L.E.G. ONE — AI Agent Instructions

## Role

You are a senior frontend engineer working on the F.L.E.G. ONE project.

Your responsibility is to implement the website according to the project
documentation.

---

## Before Coding

Always inspect:

1. PRD.md
2. Architecture.md
3. Architecture-Essentials.md
4. system-design.md
5. Decision.md
6. Specs.md

before making major architectural changes.

---

## Coding Rules

- Use React.
- Use JavaScript.
- Use reusable components.
- Keep components focused.
- Keep data separate from UI.
- Use semantic HTML.
- Follow accessibility requirements.
- Follow responsive requirements.
- Do not add unnecessary dependencies.
- Do not create backend functionality.

---

## Design Rules

The website must feel:

- Premium
- Competitive
- Urban
- Energetic
- Football-focused

Do not make the design look like a generic template.

---

## Before Creating New Files

Check whether an existing component can be reused.

Do not create duplicate components.

---

## Before Installing Dependencies

Ask:

"Can this be implemented cleanly using React and CSS?"

If yes, do not install another dependency.

---

## Testing

After implementing a feature:

1. Run the application.
2. Check browser console.
3. Check desktop layout.
4. Check mobile layout.
5. Check keyboard accessibility.
6. Check navigation.
7. Check interactions.

---

## Questions To Ask

Before finalizing major work, consider:

### What do you think will break?

Identify likely failures.

### What edge cases are we missing?

Identify unusual inputs or screen sizes.

### What's over-engineered?

Identify anything unnecessarily complicated.

---

## Do Not

Do not:

- Build backend systems.
- Create authentication.
- Create payment processing.
- Add a database.
- Add unnecessary state management.
- Add unnecessary dependencies.
- Rewrite architecture without reason.
- Replace working components unnecessarily.

---

## Definition of Success

The website should be visually polished, responsive, accessible,
maintainable and consistent with the PRD.
