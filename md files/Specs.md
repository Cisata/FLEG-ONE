# F.L.E.G. ONE — Specifications

## 1. Navbar Specification

### Desktop

Height:
72–88px

Elements:

- Logo
- Home
- Events
- How It Works
- Rankings
- About
- Contact
- Join Event

### Mobile

Show:

- Logo
- Hamburger

Hide desktop navigation.

Clicking hamburger opens mobile navigation.

---

# 2. Hero Specification

Minimum viewport height:

90vh

Elements:

- Eyebrow
- H1
- Description
- Primary CTA
- Secondary CTA
- Next event information
- Hero image

H1 should be visually dominant.

---

# 3. Event Card Specification

Each card must include:

- Image
- Event name
- Location
- Date
- Capacity
- Status
- CTA

Hover:

- Card lifts slightly.
- Image scales slightly.
- CTA transitions.

---

# 4. Player Card Specification

Include:

- Player image
- Ranking
- Name
- Nickname
- Location
- Wins
- Losses
- Goals

---

# 5. Ranking Specification

Desktop columns:

Rank | Player | Wins | Goals | Points

Mobile:

Ranking information must remain readable without horizontal scrolling.

---

# 6. Gallery Specification

Use a visually varied grid.

Images should:

- Maintain aspect ratio.
- Have rounded or consistent styling.
- Support hover interactions.
- Have alt text.

---

# 7. CTA Specification

CTA should visually stand apart from normal sections.

Headline should be large and bold.

Primary action:

JOIN THE NEXT EVENT

---

# 8. Button Specification

Buttons should have:

- Clear text
- Hover state
- Focus state
- Active state
- Accessible contrast
- Pointer cursor

---

# 9. Responsive Specification

375px:
Single column layouts.

768px:
Tablet layout.

1024px:
Laptop layout.

1440px+:
Full desktop layout.

No horizontal scrolling.

---

# 10. Animation Specification

Animations should be:

- Fast
- Subtle
- Purposeful

Avoid excessive movement.

Respect reduced-motion preferences where appropriate.
